=== GUIA DE SOBREVIVÊNCIA DO BIT ROT ===

[ COMANDOS & ATALHOS DE TECLADO ]

  • W, A, S, D : Mover o seu personagem
  • E : Interagir: Falar com NPCs, Abrir/Fechar Portas/Janelas, Entrar em Veículos, Usar Escadas
  • 1 a 5 : Usar ou Equipar item do seu Cinto
  • LCTRL / RCTRL / Botão Direito do Mouse : Mirar Arma
  • Botão Esquerdo (enquanto mira) : Atacar / Atirar / Corpo a Corpo
  • Botão Direito (em itens) : Menu de Contexto (Equipar, Largar, Consumir, Recarregar)
  • Espaço : Acordar do sono
  • F2 : Menu de Pausa / Salvar
  • F3 : Avançar o Tempo (Fast Forward)
  • F11 : Tela Cheia

[ ATALHOS DA INTERFACE ]

  • I : Inventário - Inventário do jogador e mochila
  • H : Status - Status do jogador
  • G : Equipamento (Gear) - Roupas do jogador
  • N : Proximidades - Itens próximos em recipientes/chão
  • M : Mensagens - Eventos acontecendo no jogo
  • C : Criação (Crafting) - Receitas de criação
  • ? ou / : Abrir este menu de Ajuda

[ INVENTÁRIO & ARRASTAR E SOLTAR ]

  • Clique com o botão esquerdo e segure um item para arrastá-lo pelos espaços (slots).
  • Solte os itens no seu Cinto para acesso rápido (teclas 1-5).
  • Solte os itens no menu de Equipamento (Gear) para vestir roupas.
  • Solte os itens fora da interface (no mundo) para descartá-los.

[ STATUS DO JOGADOR ]

  • Saúde (Health) : Mantenha acima de 0. Use ataduras ou remédios para se curar.
  • Energia (Stamina) : Diminui ao correr ou atacar. Recupera ao ficar parado (standby).
  • Fome & Sede : Procure por comida e água para se manter vivo.
  • Cansaço : Encontre uma cama ou um local seguro para dormir quando estiver exausto.
  • Infecção : Se for atingido por zumbis, encontre remédios rapidamente!

[ DICAS ÚTEIS ]

  • Veículos : Aproxime-se de um veículo e pressione 'E' para entrar. Pressione 'Q' para ligar/desligar o motor - Lembre-se de verificar a Mecânica!
  • Criação (Crafting) : Abra o menu de Criação ('C') para combinar itens e sobreviver - Leia livros e colete Projetos (Blueprints).
  • Combate : Sempre mire antes de atacar.
  • Iluminação : Ligue o Celular (Mobile) no seu inventário ou cinto para enxergar claramente à noite.
