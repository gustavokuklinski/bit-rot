# BIT ROT Mods

Modding Bit Rot simple tools:
- Text editor
- Notions of JSON
- Notions of Pixel Art (or another aesthetic you think funny!)

## The Editor tool: Rot Engine.
The editor is located at: `./bitrot/editor/editor.py`.
If you are running from sorce code start with: `python /bitrot/editor.py` (If not follow our ./README.md at the root)

With **Rot Engine** you can:
- Create and edit buildings for chunks
- Create and edit game sprites
- Create and edit game items, storytelling, quests...
