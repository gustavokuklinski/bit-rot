# Controls

### System controls
- **F11**: Toggle full screen (works in game)

### In game controls

**Basic controls**:
- **W/A/S/D**: Walk
- **SHIFT + W/A/S/D**: Run
- **ALT + LMB**: Shoot + Aim / Attack
- **1/2/3/4/5**: Equip and use item from Belt
- **MOUSE SCROLL / - or =**: Zoom in/Zoom out

**Game world interaction**
- **SHIFT + LMB + Drag**: Get/drop only one item from stack
- **LMB + Drag**: Place or Drop
- **RMC**: Opens context menu 
- **E**: open or close door, enter vehicle
- **R**: Reload weapon
- **Q**: Start vehicle engine
- **SPACE**: Break vehicle, wake up from sleep

**Modals**
- **I**: Opens Inventory
- **H**: Open Status
- **N**: Open Nearby
- **G**: Open Clothes
- **C**: Open Craft
- **M / ENTER**: Open Messages (enter enable chat mode)
- **TAB**: Close/Open latest open modals

**System**
- **F2 / ESC**: Pause and save
