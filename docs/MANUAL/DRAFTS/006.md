# Game Debug system command flag

Bit Rot game debug flags:

bitrot.py --debug 
          # Enter the game debug mode to accept flags
          --world="/bitrot/data.rot/lib/data/world_builds/fresh.json" # Read JSON world template
          --player="/bitrot/data.rot/lib/data/player/player.json" # Read player JSON template 
          
          # Set the game variable weather start 
          --weather="RAIN | RAIN_FOG | FOG"

          # Set the start world time
          --time="22:00"

          # Read XML file to spawn at player inventory (Allow multiple to spawn multiple items)
          --spawn-item="/bitrot/data.rot/lib/data/items/consumable_drink/consumable_drink_cola_drink.xml" 
          --spawn-item="/bitrot/data.rot/lib/data/items/consumable_drink/consumable_drink_cola_drink.xml"
          
          # For cloth the same logic
          --spawn-cloth="/bitrot/data.rot/lib/data/clothes/arms/arms_jacket.xml" 
          --spawn-cloth="/bitrot/data.rot/lib/data/clothes/arms/arms_jacket.xml" 

This flag allow to start the game instantly, just the loading screen to generate the game loading those files
