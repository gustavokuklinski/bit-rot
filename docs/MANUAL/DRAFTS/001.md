## Bit Rot LAN - Draft: 001
A LAN game based on friendship and survivor even far away. Just like Damn of the Dead, 2004, directed by: Zack Snyder, the gunshop guy.
They never know them, but messaged each other over a white board and tried to save him from starving, but he dies.
For a multiplayer, make something different, not players appearing on the game, but a only communication way to talk to the other player.
You are playing your own game. The only multiplayer thing is you can chat with other player without leaving your game. It's just Radio text based using a random LAN radio frequency. Player can only chat with each other, like they are on the other side of the island or at another archipealogo. Creativity can say. But you are playing your own local game, and the other peer too. Just find a radio frequency to chat with the player.

Your single play game can be a server using the command: 
- `%rot server open` -> This command will open the server default: 4 peers at port 7170
- `%rot server port <PORT>` -> This command will open the server with the specified port
- `%rot server peer <N>` -> This command will open the server with max peers

After connected the Host and Peers can use some commands:
- `%rot server` -> Show info about the server:
    Server IP:PORT - Max peers: 1/4
    Ping: 0ms
    Connected:
     - [S] IP : <FREQUENCY>mhz
     - [C] IP : <FREQUENCY>mhz

- `%rot <FREQUENCY> ping` -> Send a ping to peer
- `%rot <FREQUENCY> "<DIRECT_MESSAGE>"` -> Send a direct message even if you are not in range to listen yet.
- `%rot <FREQUENCY> send "<ITEM_NAME>"` -> Send an item from your inventory over the network.


At the Mobile, create a new Tab to connect peer. This will have the following: 
A text: Connect VOIP
Input field width a placeholder: 127.0.0.1:7170 (Store the connected IPs, when start typing show a dropdown the the last 3 connected IPs)
Connect VOIP

With this connection, use a little space below to display notifications like:
Connetion failed
Connected: Radio freq: [SHOW THE RADIO FREQUENCY]mhz

Peers can chat via text like survivors at a different place but together.
