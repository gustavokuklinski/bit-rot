# Map Building system
I want to create a simple building system using map tiles.
The player will be enabled to craft place map tiles at the map.

Create a new crafting tab: Build.

This build system will read the folder: `/data.rot/lib/data/craft/building`

Example of building:

wood_crate.xml
```xml
<recipe type="maptile_container" craft="create" output="Wood Crate" map_location="_map" gain_xp="[agility:0.1, maintenance:0.1]" amount="1" time="0.5">
    <ingredient name="Plank" destroy="true" amount="12" />
    <ingredient name="Nails" destroy="true" amount="24" />
    <ingredient name="[Hammer, Primitive Hammer]" destroy="false" amount="1" />
</recipe>

<recipe type="maptile" craft="create" output="roof_wooden_01_front_01" map_location="_roof" gain_xp="[agility:0.1, maintenance:0.1]" amount="1" time="0.5">
    <ingredient name="Plank" destroy="true" amount="6" />
    <ingredient name="Nails" destroy="true" amount="12" />
    <ingredient name="[Hammer, Primitive Hammer]" destroy="false" amount="1" />
</recipe>
```

The type: `maptile_container` and the `map_location="_map"` to render on map and `_roof` to render as a roof logic. 

The maptile will spawn empty at the player inventory.

The player can only 'Place' this item on context menu. Disable drop and drag-drop for this tile
