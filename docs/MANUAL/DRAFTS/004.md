# Notes system

Create a new context option to be displayed only at 'type="text"' items called 'Write'.
Use some of the Alias modal to create a little text modal to be displayed as a input textbox.
The player can write and this item must have a character lenght for example:

```xml
<item name="Sheet of paper" type="text" allow_belt="false" tip="Use to write">

        </text>

    </properties>
    <spawn chance="1" />
</item>

<item name="Notepad" type="text" allow_belt="false" tip="Use to write">

        </text>
```

After save, the player only can edit with a 'Eraser'

# Sleep mechanics

I have the following map tiles:

```xml
<map name="house_bed" type="maptile" char="house_bed" is_obstacle="false" allow_sleep="true">
    <visuals>
        <sprite file="house_bed.png" />
    </visuals>
</map>

<map name="house_bench" type="maptile" char="house_bench" is_obstacle="false" allow_sleep="true">
    <visuals>
        <sprite file="house_bench.png" />
    </visuals>
</map>
```

They have a new attribute: 'allow_sleep="true"' 
This option will be displayed at this tiles context menu.
The behabior of this tiles it to make the player sleep, and advance time in 8 hours.
When the player click sleep, advance the time in 8 hours just starting at the Darkness night. Make a tooltip saying: 'Only can sleep between: 22:00 and 00:00'. When player sleep reset some status: Health, Stamina, Anxiety, Drugs, Food and Water. If the player use the item:

```xml
<item name="Sleeping Pills" type="consumable_drugs" allow_belt="true"  allow_use="true" consume_time="0.1">
    <properties>
        <load min="1" max="5" />
        <capacity value="10" />
        
        <sprite file="consumable_drugs/consumable_drugs_infection_pills.png" />
    </properties>
    <spawn chance="1" />
</item>
```

Sleeping pills allow player to instantly sleep, but wake up with 50% Drugs, 50% Anxiety, 50% Water, 50% Food, 50% Stamina and full health.
