# Bit Rot
Developer: Gustavo Kuklinski

# Game Story
You are isolated in an island, the world had beed wipped due a plague.
The main problem is not the Zombies, but also the rain where it make them sick.
Your main mission is to secure the island as a safe haven as the previous owners 
used to make the island a vaccine distribuition and use it's matter for a global wide
spread vaccine each worked on infected people.
